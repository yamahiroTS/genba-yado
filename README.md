# 現場宿サーチ

現場と日付から、車で30分圏内の空室を楽天トラベルで探す自分用のアプリです。工具箱とは別の、独立した1ファイルのアプリです。

## ファイル

```
genba-yado/
├─ index.html   … アプリ本体（これ1つで動く）
└─ README.md    … この説明
```

## GitHubに置く（GitHub Pages で公開）

楽天のAPIは「登録したWebサイトから開いたとき」だけ応答するため、`index.html` をダブルクリックで開くだけでは空室検索ができません。GitHub Pages で公開して使います。

1. GitHubで新しいリポジトリを作る（例：`genba-yado`）
2. 「Add file」→「Upload files」で、このフォルダの中身（`index.html` と `README.md`）をドラッグし、「Commit changes」を押す
3. リポジトリの「Settings」→「Pages」で、Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分後に表示される `https://（ユーザー名）.github.io/genba-yado/` を、スマホのChromeで開いて「︙」→「ホーム画面に追加」、PCではブックマークする

※ 公開リポジトリなので、URLを知っていれば誰でも画面は開けます。ただし楽天のID・キーは各自の端末にしか保存されないため、他人が開いても検索はできません。

### 修正したとき

修正した `index.html` を同じ手順でアップロードし直すと上書きされます。スマホ側は開き直すと新しい版になります。

## 準備（最初に1回）

空室は楽天トラベルの公式API（楽天ウェブサービス）から取得します。無料ですが、自分用の「アプリID」と「アクセスキー」が必要です。

1. 楽天ウェブサービス（https://webservice.rakuten.co.jp/）に楽天IDでログインし、アプリを新規登録する
2. 登録画面で、アプリケーションタイプは「Webアプリケーション」、APIアクセススコープは「楽天トラベルAPI」にチェックし、「許可されたWebサイト」に GitHub Pages のドメインだけ（`（ユーザー名）.github.io`。`https://` と最後の `/` は付けない）を入れる
   - 「許可されたIPアドレス」は空欄にする（スマホの回線はIPが変わるため）
3. 表示された「アプリID」と「アクセスキー（pk_で始まるもの）」を控える
4. アプリを開き、右上の「設定」にIDとキーを入れて保存する

※ IDとキーは index.html の中に書き込まないでください。必ずアプリの「設定」画面から入れます。

### 使い方

- **現場**：「USSオークション会場」（USS公式の会場案内にある20会場）から選ぶか、住所（または「緯度,経度」）を直接入力する。よく行く病院などは「設定」→「登録した現場」に追加しておくと選ぶだけで済む
- **人数**：喫煙者（自分を含む、0〜2人）と禁煙者（0〜4人）を選ぶ。1人1室で探す
- **結果の並び**：東横イン → ルートイン → HOTEL AZ → その他。同じグループ内では基準料金（初期値8,000円）以内、現場に近い順
- **予約**：東横イン・ルートイン・HOTEL AZは公式サイト、それ以外は楽天の予約ページを開く

### 検索の決まりごと

- 範囲は「車で30分」を直線距離に直した範囲（初期値で約13km）。所要時間は目安なので、結果の「現場までのルート」で確認する
- 1泊の予算上限は初期値14,000円（「設定」で変更できる）
- まず朝食付きプランだけで探し、1軒もなければ朝食なしも含めて探し直す
- ドミトリー・カプセル・ゲストハウス・民泊・共同トイレなどは除外（除外する語は「設定」で編集できる）
- 禁煙者がいるときは、禁煙室が何室まで取れるかを確認して表示する（例：「禁煙は2室まで（禁煙者2名なら宿泊可）」）
- 喫煙室は楽天APIで絞り込めないため、プラン名から判定する。喫煙者2人のときの室数は予約画面で確認する
- 空室・料金は楽天トラベルの情報。最終的な空き・料金・部屋タイプは予約画面で確認する
- 優先チェーンの順番は「設定」の優先チェーン欄で行を入れ替えると変えられる
